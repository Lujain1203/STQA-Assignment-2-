# Bug Reports - AcademyBugs

This document summarizes the bugs found on **[AcademyBugs](https://academybugs.com)** during testing.  
Each bug report includes its **type**, **severity**, **frequency**, and **steps to reproduce**.

## Crash Bugs

### 1. Page Freezes When Changing Currency
**Severity:** High  
**Issue Type:** Crash  
**Frequency:** Every Time  

#### Steps to Reproduce
1. Open [https://academybugs.com](https://academybugs.com)  
2. Click the **Find Bugs** link on the navigation bar  
3. Open any product  
4. Change the **currency** from the right side menu  

**Expected Result:**  
The currency should update smoothly.  

**Actual Result:**  
The page freezes completely when changing the currency.

### 2. Page Becomes Unresponsive When Selecting Number of Results
**Severity:** High  
**Issue Type:** Crash  
**Frequency:** Every Time  

#### Steps to Reproduce
1. Open [https://academybugs.com](https://academybugs.com)  
2. Click the **Find Bugs** link on the navigation bar  
3. Click the **buttons** to show a specific number of results (top-left corner)  

**Expected Result:**  
The selected number of results should display correctly.  

**Actual Result:**  
The page becomes unresponsive when clicking on the number of results.

## Visual Bug

### 3. Sign In Button Overlaps Footer
**Severity:** Low  
**Issue Type:** Visual  
**Frequency:** Every Time  

#### Steps to Reproduce
1. Open [https://academybugs.com](https://academybugs.com)  
2. Click the **Find Bugs** link on the navigation bar  
3. Open a product with **no color selection options**  
4. Scroll to the bottom of the right side menu  

**Expected Result:**  
The **Sign In** button should appear clearly above the footer.  

**Actual Result:**  
The **Sign In** button overlaps with the footer.
